# /brief — 회의 전 브리핑

**목적**: 다음 회의 아젠다 준비용 자동 브리핑

**사용법**:
```
/brief
```

**사용 시기**: 다음 회의 전날 또는 당일 아침

---

## 📋 생성 항목 (순서대로)

### 1️⃣ 헤더

```markdown
# 📋 회의 전 브리핑

**생성 날짜**: YYYY-MM-DD {HH:MM}  
**회의 예상**: {언제 (사용자가 알려준 경우)}

---
```

### 2️⃣ 📍 즉시 확인할 사항

기한이 **오늘이거나 내일**인 액션:

```markdown
## 📍 즉시 확인할 사항

⚠️ **기한이 오늘인 액션 (반드시 오늘 중 완료 또는 진행 상황 공유)**

- **A-0023** (Bob): 세션 저장소 비교 분석
  기한: 2026-03-15
  상태: 진행중
  진행률: 70%
  → "결과가 나왔나요? 아니면 기한 연장이 필요한가요?"

---

⏰ **기한이 내일인 액션 (다음 회의에서 결과 공유)**

- **A-0021** (Bob): PoC — 세션 기반 인증 구현
  기한: 2026-03-19
  상태: 진행중
  진행률: 40%

- **A-0022** (Carol): 세션 기반 FE 연동 검토
  기한: 2026-03-19
  상태: 대기중 (Bob의 PoC 결과 대기)
```

---

### 3️⃣ 🎯 진행 중인 액션 전체

모든 **열린 액션** (진행중 + 대기중 + 보류):

```markdown
## 🎯 진행 중인 액션 (N개)

| 담당 | 제목 | 기한 | 상태 | 진행률 |
|---|---|---|---|---|
| Bob | A-0021: PoC 구현 | 2026-03-19 | 진행중 | 40% |
| Carol | A-0022: FE 연동 | 2026-03-19 | 대기중 | 0% |
| Bob | A-0023: 저장소 분석 | 2026-03-15 | 진행중 | 70% |
| Alice | A-0024: 요구사항 정리 | 없음 | 진행중 | 50% |

**기한 임박 ⚠️**: A-0023 (기한 1일 남음)
**오래된 액션 🔄**: A-0015 (35일 비활동)
```

---

### 4️⃣ 💥 최근 번복된 결정

지난 N주 동안 **상태가 "번복됨"으로 바뀐 D**:

```markdown
## 💥 최근 번복된 결정

### D-0005: 프론트엔드 프레임워크 선택 (React → Vue)

- **이전**: [[D-0002-React선택]] (2026-02-20)
- **현재**: [[D-0005-Vue로변경]] (2026-03-12)
- **이유**: React 번들 크기 이슈, Vue가 더 가벼움 [[2026-03-12]]
- **영향 액션**:
  - [[A-0018]] (Mike): React → Vue 마이그레이션 (이미 진행 중)

→ "이전 결정에 대해 어떻게 생각하세요?"
```

번복이 없으면:
```markdown
## 💥 최근 번복된 결정

(이번주는 없음)
```

---

### 5️⃣ ❓ 미해결 질문 (Open Questions)

지난 회의들에서 **미결로 남겨진 사항**:

```markdown
## ❓ 미해결 질문 (지난 회의에서)

### 1. 세션 저장소: Redis vs DB?
- **출처**: [[2026-03-05]] 주간개발
- **상태**: [[A-0023]] (Bob이 조사 중)
- **진행**: 현재 비교 분석 중, 기한 2026-03-15

→ "A-0023 결과를 이번 회의서 논의하세요"

### 2. 기존 사용자 마이그레이션 전략
- **출처**: [[2026-03-05]] 주간개발
- **상태**: 아직 Action 미배정 ⚠️
- **담당자**: 미정

→ "이번 회의서 누가 담당할지 정하세요"

### 3. 결제 팀과의 API 스펙 동기화
- **출처**: [[2026-03-12]] 주간개발
- **상태**: [[A-0024]] (Alice의 요구사항 정리 중)
- **기한**: TBD

→ "Alice의 진행 상황을 확인하세요"
```

미결이 없으면:
```markdown
## ❓ 미해결 질문

(현재 미결 사항 없음)
```

---

### 6️⃣ 📌 다음 회의 추천 아젠다

위 정보들을 종합해서 제안하는 아젠다:

```markdown
## 📌 다음 회의 추천 아젠다

### 우선순위 1️⃣ (필수 논의)

1. **A-0023 결과 공유** (Bob) — 기한 오늘
   - 세션 저장소 Redis vs DB 비교 분석
   - 의사결정 필요: [[D-0006]]의 "저장소 선택" 미결 결정

2. **기존 사용자 마이그레이션 전략** — 미결 1개월
   - 아직 Action 미배정
   - 누가 담당할지, 언제까지 조사할지 정하기

### 우선순위 2️⃣ (상태 공유)

3. **A-0021 / A-0022 진행 상황**
   - PoC 진행률 40% (Bob)
   - FE 연동 기한 내일 (Carol)

4. **번복 결정 [[D-0005]] 영향도 평가**
   - React → Vue 변경으로 인한 추가 작업 있나?
   - A-0018 (마이그레이션) 진행 상황?

### 우선순위 3️⃣ (선택)

5. **API 스펙 동기화** (Alice)
   - 결제 팀과의 협업 진행 상황

---

## ✏️ 회의 후 권장 사항

1. 결정된 사항 → `/ingest` 커맨드로 즉시 wiki 반영
2. 새 액션 → wiki/actions/actions.md에 추가
3. 기한 변경 액션 → 상태 업데이트
4. 번복된 결정 → D 페이지에 "번복 기록" 추가
```

## 💡 팁

### brief의 주기
- **권장**: 주 1회 (회의 전날 또는 당일 아침)
- **최소**: 회의마다 1회
- **추가**: 액션 기한 변경 시 즉시 실행 (변화 감지)

### 회의 중에는
- brief를 스크린에 띄우고 참고하기
- 결정 사항이 나오면 적어두기
- 회의 끝나고 바로 /ingest로 반영

### 회의 후에는
1. 새 결정/액션 → /ingest로 wiki 갱신
2. 기한 변경 → actions.md 수동 업데이트
3. 다음 회의 전에 /brief 다시 실행
